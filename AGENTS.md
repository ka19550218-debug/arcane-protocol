# ARCANE PROTOCOL - Codex Instructions

## Project

ARCANE PROTOCOL is a browser-based cyberpunk gesture-controlled game
for the Admit Hackathon Motion 2026.

The player sits in front of a laptop webcam.
After camera permission is granted, the application should be usable
without keyboard or mouse.

## Stack

Use:

- Vite
- Vanilla JavaScript
- HTML
- CSS
- MediaPipe
- Canvas 2D when appropriate
- localStorage for local scores

Do NOT introduce:

- React
- Next.js
- TypeScript
- backend
- database
- 3D engines
- additional frameworks

unless explicitly requested.

## Development rules

1. Work on ONE requested task at a time.
2. Do not implement future milestones unless explicitly requested.
3. Do not rewrite working code without a clear reason.
4. Do not modify unrelated files.
5. Prefer simple readable code over clever abstractions.
6. Keep modules reasonably small.
7. Reuse existing functionality instead of duplicating it.
8. Before making a large architectural change, explain why it is needed.
9. After implementation, run relevant checks/build if possible.
10. Fix errors introduced by your own changes.
11. Do not add unnecessary dependencies.
12. Preserve working features when adding new ones.

## Important

The deadline is very short.

Priority order:

1. Working application
2. Stable gesture recognition
3. Error feedback
4. Complete playable scenario
5. UX and visual quality
6. Additional features

Never sacrifice a working core feature for an optional feature.

## Documentation

Detailed project information lives in /docs.

Do not read every documentation file for every small task.

Read only the documentation relevant to the current task.

## Response style

After completing a task, briefly report:

- files changed
- what was implemented
- how to test it
- any known issue

Keep explanations concise.
