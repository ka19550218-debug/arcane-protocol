# Hackathon Requirements

## Mandatory

The application must:

1. Recognize movements in real time from the webcam in the browser.
2. Support at least 3 different movements or gestures.
3. Give clear visual feedback when a gesture is recognized.
4. Provide a complete scenario from beginning to result.
5. Work in the browser without requiring installation.

## Mandatory Error Mode

The application must detect incorrect or inaccurate movement
and provide a concrete correction.

Bad:

"Gesture not recognized."

Good:

"Open your fingers wider."

Good:

"Move your hand slightly higher."

Good:

"Keep your palm facing the camera."

## Evaluation

Maximum: 100 points.

- Functionality: 30
- Error Mode: 20
- Technical implementation: 20
- UX and design: 15
- Originality: 10
- Bonuses: 5

## Bonuses

Possible bonus features:

- custom gesture recognition logic
- leaderboard / progress
- phone camera adaptation
- sound and visual effects

## Development constraint

The main project logic must be created during the hackathon.

Git commit history may be inspected.

The project needs a public GitHub repository and README with
run instructions.

A deployed version is strongly preferred.

## Project priorities

Never break mandatory functionality to implement a bonus feature.
